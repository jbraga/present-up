# PresentUp Design Identity Summary

## 1. Core Concept
The design identity is a "Premium Android Native" aesthetic, utilizing Material Design 3 principles. It prioritizes a clean, airy interface with soft elevations and a purposeful hierarchy of information.

## 2. Visual Palette (RGB Codes)
- Primary Blue: rgb(28, 116, 233) — Used for primary actions and active states.
- Background: rgb(248, 250, 252) — An ultra-light grey for a premium feel.
- Surface/Cards: rgb(255, 255, 255) — Pure white for interactive containers.
- Primary Text: rgb(30, 41, 59) — Deep slate for high legibility.
- Secondary Text: rgb(100, 116, 139) — Muted slate for labels.

## 3. Typography
The app exclusively uses the Lexend font family for its high readability and modern feel.

- Titles: Lexend SemiBold/Medium (24px - 18px).
- Body: Lexend Regular (14px).
- Labels: Lexend Medium (12px, often uppercase).

## 4. Layout Characteristics
- Cards: 16px corner radius with subtle 1px borders and soft shadows.
- Spacing: Consistent 20px horizontal margins and 16px vertical spacing between elements to maintain an "uncluttered" look.
- Interaction: Large touch targets and a clear Bottom Navigation Bar (Classes, Students, Attendance) with minimalist linear icons.
